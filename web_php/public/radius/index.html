ربط راوتر مايكروتك جديد (NAS)

لتشغيل نظام المصادقة والحسابات، قم بإضافة راوترات المايكروتك المتصلة بالسيرفر. ضع عنوان IP العميل الذي يرسل طلبات RADIUS، وإذا أردت ربط باقات محددة بالراوتر فاملأ حقل IP الباقات بالمايكروتك.

إذا تم تفعيل هذا الخيار، سيظهر الراوتر لجميع الموزعين ولن يكون حصرياً لوكيل واحد.

دليل توثيق وإعداد أجهزة الراوتر (UDP & RadSec TLS)

💡 المحرك المزدوج (Dual-Stack RADIUS Engine)

يدعم نظام SASMAN استقبال طلبات الراديوس بنمطين متزامنين في نفس الوقت بدون أي تعارض؛ حيث تعمل راوتراتك المحلية في البرج أو الحاوية بنمط UDP السريع، بينما تعمل الفروع البعيدة التي تعمل خلف CGNAT بنمط RadSec TLS المشفر.

شرح شارات الحالة في الجدول:

متصل RadSec 🟢

الراوتر متصل حالياً بالسيرفر عبر جلسة mTLS مشفرة ونشطة، وخاصية القطع العكسي تعمل بنجاح.

شهادة صادرة ⚪

تم إصدار شهادات التشفير الرقمية للراوتر، وبانتظار قيامك باستيرادها وربطها بالمايكروتك.

UDP مباشر 🔵

الراوتر يعمل بنمط الـ UDP المباشر القياسي (منافذ 1812 و 1813) للشبكات المحلية بدون شهادات.

وظائف الأزرار في الجدول:

  • 🔑 شهادة: توليد شهادة عميل رقمية ومفتاح مشفر خاص بالراوتر موقعين من Root CA الداخلي.
  • 📥 الحزمة: تحميل ملف مضغوط (ZIP) يحتوي على الشهادات وملف التكوين التلقائي.
  • 🚫 إبطال: إلغاء شهادة الراوتر وفصل اتصاله بالسيرفر فوراً لأسباب أمنية.
  • ⚡ إعداد راديوس سريع: برمجة راوتر المايكروتك المحلي المرتبط بالحاوية تلقائياً بضغطة زر واحدة.

⚡ نمط الـ UDP المحلي (أعلى سرعة وأسهل إعداد)

مناسب عندما يكون سيرفر SASMAN والمايكروتك في نفس البرج أو نفس الكابينة أو داخل نفس الشبكة المحلية (LAN).

📋 الأوامر الجاهزة لتنفيذها في Terminal المايكروتك:

# 1. إضافة خادم الراديوس المحلي
/radius add address=172.17.0.1 secret=123456 service=hotspot,ppp,wireless authentication-port=1812 accounting-port=1813 timeout=3000ms

# 2. تفعيل استقبال طلبات طرد وفصل المستخدمين
/radius incoming set accept=yes port=3799

* استبدل 172.17.0.1 بـ IP السيرفر المحلي لديك إذا كان مختلفاً، وتأكد من تطابق الكلمة السرية (Secret).

🛡️ نمط RadSec TLS (التشفير التام والربط للفروع البعيدة خلف CGNAT)

مناسب للراوترات البعيدة عبر الإنترنت العام، أو الراوترات التي تعمل خلف شركات اتصالات تطبق الـ CGNAT ولا تمتلك Real IP.

خطوات الإعداد خطوة بخطوة:

  1. اضغط على زر "🔑 شهادة" أمام الراوتر في الجدول لتوليد الشهادة المشفرة.
  2. اضغط على زر "📥 الحزمة" لتحميل ملف الـ ZIP وفك الضغط عنه (يحتوي على ca.crt و agent.crt و agent.key).
  3. اسحب الملفات الثلاثة وضعها في قائمة Files داخل برنامج Winbox.
  4. افتح Terminal المايكروتك ونفذ الأوامر التالية:
# 1. استيراد الشهادات الثلاثة في المايكروتك
/certificate import file-name=ca.crt passphrase=""
/certificate import file-name=agent.crt passphrase=""
/certificate import file-name=agent.key passphrase=""

# 2. ربط الـ RADIUS بنمط RadSec عبر منفذ 2083
/radius add address=YOUR_SERVER_IP protocol=radsec certificate=agent.crt service=hotspot,ppp,wireless secret=radsec timeout=3000ms authentication-port=2083 accounting-port=2083

# 3. تفعيل استقبال أوامر القطع
/radius incoming set accept=yes port=3799

* استبدل YOUR_SERVER_IP بعنوان الـ IP العام أو اسم النطاق لسيرفرك المركزي.

🔄 كيف تعمل ميزة القطع والتحكم العكسي (Reverse Disconnect)؟

في الراوترات البعيدة التي تعمل خلف CGNAT، لا يمكن للسيرفر الاتصال بالراوتر من الخارج لطرده أو فصل المشتركين المنتهيين. مع SASMAN RadSec، يقوم الراوتر بفتح اتصال TLS دائم بالسيرفر، وعند انتهاء اشتراك مستخدم يقوم السيرفر بضخ أمر القطع عكسياً عبر نفس القناة المفتوحة ليتم طرد المشترك فوراً بدون الحاجة لـ Real IP أو فتح أي بورت!

مخطط تدفق الاتصال العكسي:
[راوتر المايكروتك البعيد] ──(اتصال TLS دائم :2083)──▶ [سيرفر SASMAN المركزي]
[راوتر المايكروتك البعيد] ◀──(أمر Disconnect العكسي)── [سيرفر SASMAN المركزي]

🌐 كيف تتم المصادقة عندما تكون بيانات المشترك في حاوية الوكيل المحلي؟

تحتفظ كل حاوية وكيل بقاعدة بيانات مشتركيها محلياً لضمان الخصوصية وسرعة الأداء. عند وصول طلب من راوتر برج بعيد للسيرفر المركزي، يقوم السيرفر بالاستعلام اللحظي عبر نفق الـ WebSocket المشفر الخاص بحاوية الوكيل في أجزاء من الثانية.

🛡️ كيف يميز السيرفر بين الوكيل A والوكيل B ويعزل البيانات؟

1. عبر شهادة الراوتر المشفرة (RadSec CommonName & Mapping):

كل برج يحمل شهادة رقمية فريدة تتبع للوكيل المالك له؛ بمجرد اتصال الراوتر بالسيرفر، يعرف السيرفر فوراً أن هذا البرج يتبع الوكيل A، ويقوم بتوجيه طلبات مشتركيه حصرياً إلى حاوية الوكيل A.

2. عبر نطاق التجوال المشترك (User Realm / Roaming):

إذا كان المشترك تابعاً لـ الوكيل A ولكنه متصل من برج يتبع الوكيل B، يكتب حسابه بصيغة (user@agent_a)، فيتعرف السيرفر على الوكيل A ويفحص حسابه ويفتح له النت على برج الوكيل B مع حفظ رصيده وسرعته!

3. عبر الكروت المركزية الموحدة (Global Roaming Vouchers):

الكروت الصادرة مركزياً من السيرفر العام يتم التحقق منها مباشرة دون الحاجة للرجوع لأي وكيل محلي.

مخطط تدفق المصادقة وعزل الوكلاء:
[راوتر البرج] ──(طلب مصادقة RadSec)──▶ [سيرفر SASMAN المركزي]
[سيرفر SASMAN المركزي] ──(فحص الشهادة وتحديد الوكيل A)──▶ [حاوية الوكيل A عبر نفق WebSocket]
[حاوية الوكيل A] ──(التحقق من قاعدة البيانات المحلية والرد بالسرعات)──▶ [فتح الإنترنت للمشترك]

كود ربط المايكروتك التلقائي (RadSec mTLS)

التثبيت الفوري بضغطة زر واحدة

يقوم هذا السطر بتنزيل شهادة الوكيل الخاصة بك (...) وشهادة الجذر CA وتثبيتها داخل الراوتر، ثم ضبط عميل الـ RadSec المشفر وتفعيل الراديوس على السيرفر المركزي (167.86.73.203:2083) تلقائياً بالكامل دون الحاجة لرفع الملفات يدوياً.

خطوات التشغيل في المايكروتك:

  1. افتح تطبيق Winbox أو اتصل بالراوتر عبر SSH / WebFig.
  2. افتح شاشة الأوامر Terminal في المايكروتك.
  3. الصق السطر المنسوخ بالأعلى واضغط Enter.
  4. سيقوم المايكروتك بتحميل الشهادات وضبط الراديوس وتظهر لك رسالة النجاح الخضراء:
    [SUCCESS] SASMAN RadSec Provisioned Successfully!

إضافة واكتشاف جهاز شبكة جديد

أدخل عنوان IP وبيانات الدخول للراوتر أو السويتش أو رابط البرج. يمكنك الضغط على "🔍 اختبار واكتشاف" ليقوم النظام تلقائياً بقراءة الموديل، المنافذ، ونظام التشغيل وتحديد نوع الجهاز تلقائياً.
